# חדשות בזמן אמת – N12 & Ynet

תוסף Chrome שמציג פס חדשות צף ונגלל על כל אתר, עם עדכונים חיים מצ'אט הכתבים של N12 ומהמבזקים של Ynet.

A Chrome extension that shows a floating, scrolling news ticker on any page, with live updates from N12's reporters chat and Ynet breaking news.

## תכונות

- **שני מקורות:** צ'אט הכתבים של N12 ומבזקי Ynet. אפשר לכבות כל מקור בנפרד.
- **מהירות גלילה מתכווננת:** מחוון בחלון התוסף (20–200 פיקסלים לשנייה), שמתעדכן מיד בכל הטאבים.
- **גרירה ושינוי גודל:** אפשר להזיז את הפס לכל מקום במסך ולשנות את הרוחב והגובה שלו. הגופן מתאים את עצמו לגובה.
- **מסך מלא:** הפס ממשיך להופיע גם כשסרטון או דף עוברים למסך מלא.
- **בלי הפרעה לדף:** הפס מבודד ב-Shadow DOM, כך שהעיצוב שלו והעיצוב של האתר לא משפיעים זה על זה.
- ההגדרות (מקורות, מיקום, גודל ומהירות) נשמרות גם אחרי סגירת הדפדפן.

## התקנה

התוסף לא מופיע בחנות של Chrome, ולכן מתקינים אותו ידנית:

1. מורידים את הקוד: `git clone https://github.com/Elimeshi1/news-extension.git`
   או דרך **Code → Download ZIP** ומחלצים.
2. פותחים את `chrome://extensions`.
3. מדליקים את **מצב מפתח** (Developer mode) בפינה העליונה.
4. לוחצים על **טען פריט לא ארוז** (Load unpacked) ובוחרים את תיקיית הפרויקט.

## שימוש

1. לוחצים על אייקון התוסף בסרגל הכלים.
2. מדליקים את **הצג וידג'ט**. הפס יופיע בטאב הפעיל.
3. בחלון התוסף אפשר לבחור מקורות ולכוון את מהירות הגלילה.
4. כדי להסתיר את הפס לוחצים על ✕ שבקצה שלו, או מכבים את המתג בחלון התוסף.

## איך זה עובד

| רכיב | תפקיד |
|------|--------|
| `background.js` | Service worker שמושך את צ'אט הכתבים של N12 מ-Firebase כל 5 דקות ואת ה-RSS של Ynet כל 2 דקות, שומר עד 10 פריטים לכל מקור ומשדר עדכונים לטאבים. |
| `content.js` | מזריק את הפס לדף. הגלילה מבוססת `requestAnimationFrame`, ופריטים חדשים נוספים בלי לקפוץ או להתחיל מחדש. |
| `popup.html` / `popup.js` | חלון ההגדרות: הצגה/הסתרה, מקורות ומהירות. |

### הרשאות

- `storage`: שמירת ההגדרות והחדשות האחרונות.
- `alarms`: תזמון המשיכה התקופתית של החדשות.
- `activeTab` + `scripting`: הזרקת הפס לטאב שבו מפעילים את התוסף בלבד, בלי גישה קבועה לכל האתרים.
- גישה ל-`channel-2-news.firebaseio.com` ול-`www.ynet.co.il` בלבד, לצורך משיכת החדשות.

התוסף לא אוסף מידע ולא שולח נתונים לשום שרת מלבד משיכת החדשות מהמקורות האלה.
